# app-scout--v0.4.0 (2026-11-13)
Minor release, based on preview `app-scout--v0.4.0-preview.1` plus the version bump.

## Changes since 0.3.3
- feat: an Ask bar under the map. What you select becomes a chip next to the input; the raw context text is no longer shown.
- feat: a chat above the bar with your questions and Claude's answers; it folds, and opens when an answer arrives.
- feat: a Data set select in the toolbar replaces the sessions panel.
- **Breaking:** the chat card (`ui/dock.html`, the `dock` tool) is removed. In Claude Desktop Chat a map question is no longer pushed into the chat: copy and paste it. Claude Code is unchanged.

## Evidence
npm test 17/17 · `claude plugin validate . --strict` passed · e2e 23/23 (screenshots in the release pull request). Not covered by e2e: the select following a brand-new scout, the status line after "Ask Claude to group".

## Install
`claude plugin marketplace add chauvoluuhuong/app-scout` then `claude plugin install app-scout@app-scout` (update: `claude plugin update app-scout@app-scout`).
